# 개인정보 및 보안 경계

## 수집하는 정보

- YouTube Music 미디어 세션이 공개하는 곡명, 아티스트, 앨범, 곡 길이
- 재생 상태 변화와 시각
- 재생 위치, 실제 청취 시간, 완주 여부
- Android가 생성한 기기 식별값

## 수집하지 않는 정보

- Google 계정 아이디와 비밀번호
- Google 또는 YouTube 로그인 쿠키·OAuth 토큰
- 연락처, 사진, 위치, 마이크 음성
- 다른 앱 알림의 제목이나 내용

앱은 Android의 알림 접근 권한을 받아 활성 미디어 세션 목록에 접근하지만, 코드에서는 패키지명이 `com.google.android.apps.youtube.music`인 세션만 처리합니다.

## 저장 위치

- 전송 전: 앱 전용 SQLite 데이터베이스
- 전송 후: 사용자가 소유한 Cloudflare D1 데이터베이스
- `INGEST_TOKEN`: Android Keystore로 보호된 키를 사용해 암호화 저장
- `READ_TOKEN`: Android 앱에 저장하지 않으며 ChatGPT/MCP 연결에만 사용

## 알려진 한계

- Android 또는 YouTube Music 업데이트로 미디어 세션 메타데이터 형식이 바뀌면 일부 필드가 누락될 수 있습니다.
- 앱 강제 종료, 알림 접근 권한 해제, 제조사 절전 정책 적용 중에는 수집이 중단될 수 있습니다.
- `music_now`는 마지막 동기화 시점 기준이므로 네트워크 상태에 따라 약 1분 이상 늦을 수 있습니다.
- 개인 Worker URL과 토큰을 아는 사람은 허용 범위의 데이터에 접근할 수 있으므로 토큰을 공개하면 안 됩니다.
